# Tham chiếu cấu hình

Mọi key, ý nghĩa và mặc định. Override bằng biến môi trường theo cú pháp `Section__Key` (hai gạch dưới).

| Key | Mặc định | Ý nghĩa |
|---|---|---|
| `IdentityServer:LocalRole` | `SuperAdmin` (repo team: không có key) | **Công tắc chọn kiểu đăng nhập.** Trống `""` hoặc thiếu key ⇒ SSO qua IdentityServer (triển khai thật). Có giá trị (`SuperAdmin`/`Admin`/`TeamDev`/`User`) ⇒ tự đăng nhập cục bộ bằng user mang **đúng tên vai trò** (vd `TeamDev`, tự tạo ở lần đăng nhập đầu — không seed sẵn) với đúng vai trò đó — **nguồn duy nhất của vai trò ở chế độ này**, đặt thấp hơn để thử màn hình dưới góc nhìn quyền hạn chế. Gõ sai tên vai trò ⇒ app dừng lúc khởi động; đang bật ⇒ log `Warning` mỗi lần khởi động. Đổi **không cần build lại** — xem [screens-and-permissions.md#xác-thực--hai-chế-độ-không-có-mật-khẩu-trong-app)
| `ConnectionStrings:DefaultConnection` | `Server=SONGLONG;...` | Chuỗi kết nối, **đồng thời chọn provider DB**: có giá trị ⇒ SQL Server (bật `EnableRetryOnFailure`); trống/thiếu ⇒ Sqlite file `ICOGenerator.db`. Chạy Sqlite bằng env var rỗng `ConnectionStrings__DefaultConnection=` |
| `AgentWorkspace:RootPath` | `C:\Study App\ICOGeneratorWorkspaces` | Thư mục gốc workspace agent, đồng thời là nơi lưu file đính kèm feedback (`.feedback-uploads/`). **Phải đổi theo máy** |
| `AllowedCommands` | dotnet, git status/diff/add/commit/push/checkout/remote get-url, dir, npm, node | Whitelist lệnh cho `RunCommand` |
| `AllowedFileExtensions` | .cs .cshtml .css .scss .ts .js .json .md .txt .sln .csproj .html .sql .yml .yaml | Whitelist đuôi file cho tool file |
| `BoschTemplate:BackendRepoUrl/FrontendRepoUrl/Branch` | trống | Repo khung Bosch để lấy skeleton — clone ra thư mục tạm rồi **chép nội dung** (bỏ `.git`) vào repo đích của dự án; trống = bỏ qua. Nạp URL private qua env |
| `Commands:TimeoutSeconds` | 300 | Timeout mỗi lệnh `RunCommand` do agent gọi. 120s cũ cắt ngang đúng lệnh đắt nhất (`npm install` một skeleton Angular) |
| `Commands:BuildTimeoutSeconds` | 600 | Timeout mỗi lệnh của **cổng biên dịch** (app tự chạy sau bước Implementation — xem [delivery-pipeline.md](delivery-pipeline.md#cổng-biên-dịch-implementation--buildfix)). Rộng hơn vì lúc đó agent đã xong, chỉ tốn thời gian tường |
| `Workers:MaxConcurrentAgentTasks` | 1 | Số agent task chạy song song tối đa của `AgentTaskWorker` (trần cứng 16). Mặc định 1 = tuần tự như trước (an toàn cho LLM tự host); tăng 2–4 khi endpoint model chịu tải song song. Mỗi project luôn chỉ một task một thời điểm |
| `PullRequest:RemoteName/BaseBranch/GitHubToken` | origin / main / trống | Bước PR: token trống hoặc remote không phải GitHub ⇒ fallback link compare. `BaseBranch` cũng là tên nhánh đầu tiên khi một repo đích phải được `git init`. Token CHỈ dùng để gọi API tạo PR — quyền `git push` lấy từ credential của máy chủ (khóa SSH / credential helper), xem [delivery-pipeline.md](delivery-pipeline.md#bước-pull-request) |
| `PullRequest:CommitterName/CommitterEmail` | `ICOGenerator` / `icogenerator@localhost` | Danh tính commit đặt cho repo đích khi máy chủ **chưa** có `user.name`/`user.email` — thiếu nó thì `git commit` fail ở tận bước cuối pipeline. Máy chủ đã cấu hình sẵn thì hai key này không được đụng tới |
| `Notifications:BaseUrl` | trống | URL gốc app để dựng link tuyệt đối trong Teams/email |
| `Notifications:Teams:{Enabled,WebhookUrl}` | tắt | Incoming Webhook Teams. Fail-open |
| `Notifications:Email:{Enabled,Host,Port,UseStartTls,Username,Password,From,To}` | tắt / 587 STARTTLS | SMTP qua MailKit. Password qua env. Fail-open. `UseStartTls=true` + `Port=465` ⇒ implicit TLS (`SslOnConnect`); `true` + cổng khác ⇒ STARTTLS; `false` ⇒ không mã hóa |
| `Notifications:BoschEmail:{Enabled,BaseUrl,SendMailApi,ApiKey,FromEmail,To,OnlySendToTesterEmail,TesterEmail}` | tắt / `api/Email` | Email Server API nội bộ Bosch (HTTP) thay SMTP. ApiKey qua env. `OnlySendToTesterEmail` = chốt an toàn non-prod. Fail-open |
| `Llm:ClaudeCode:BinaryPath` | trống | Đường dẫn lệnh `claude` cho model có Endpoint `claude-code://…` ([llm-and-prompts.md](llm-and-prompts.md#claude-qua-claude-code-cli-gói-claude-promax-chỉ-cho-máy-cá-nhân)). Trống ⇒ tự tìm: PATH, các chỗ trình cài hay đặt, rồi bản đi kèm extension Claude Code của VS Code |
| `Llm:Proxy:{Enabled,Address}` | true / `http://127.0.0.1:3128` | Proxy công ty cho lời gọi LLM ra ngoài (client "proxied"); code mặc định coi Enabled=true nếu **thiếu key**. Address là relay px/CNTLM ⇒ Claude Code CLI cũng đi qua nó (xem `Llm:ClaudeCode:Environment`). Proxy chết thì "Test Connection" gọi tên proxy thay vì đổ cho endpoint ([llm-and-prompts.md](llm-and-prompts.md#thêm-một-model-mới)) |
| `Llm:Proxy:UseDefaultCredentials` | false | Trả lời `407` bằng tài khoản Windows đang chạy app (Negotiate/NTLM) ⇒ trỏ **thẳng** `Address` vào proxy công ty, không cần relay px/CNTLM. Chỉ có tác dụng trên Windows; chạy như service thì tài khoản service phải có quyền qua proxy |
| `Llm:Proxy:BypassList` | `[]` | Host đi thẳng, không qua proxy: host đầy đủ (`llm.corp.local`) hoặc hậu tố tên miền (`.bosch.com`) — **không phải regex** (`LlmProxy` tự escape). Tương đương `no_proxy`; thiếu nó thì bật proxy là giết mọi model tự host nội bộ |
| `Llm:ClaudeCode:Environment` | `{}` | Biến môi trường đặt đè cho tiến trình `claude` (tên → giá trị; rỗng = gỡ biến). CLI không đi qua `Llm:Proxy` mà tự ra mạng theo `HTTPS_PROXY`… — mặc định `HTTPS_PROXY`/`HTTP_PROXY` lấy theo `Llm:Proxy:Address` khi proxy bật và `UseDefaultCredentials = false` (relay px/CNTLM); khai ở đây để đè ([llm-and-prompts.md](llm-and-prompts.md#claude-qua-claude-code-cli-gói-claude-promax-chỉ-cho-máy-cá-nhân)). Đổi xong phải khởi động lại app |
| `Llm:SourceUpload:{MaxFileBytes,MaxHtmlFileBytes}` | 10MB / 30MB | Trần cỡ MỖI file tài liệu nguồn lúc upload. HTML có trần riêng vì mockup xuất "tự chứa" nhồi font/thư viện/ảnh base64 — xem [requirement-flow.md](requirement-flow.md#tài-liệu-nguồn-ảnh-và-call-log). Cả request upload vẫn chặn ở 60MB (`RequestSizeLimit` của `UploadSource`) |
| `Llm:SourceUpload:{MaxImagesPerCall,MaxTotalImageBytes,MaxTextCharsPerFile}` | 12 / 20MB / 20.000 | Trần phần ảnh (số ảnh, dung lượng gói tin) và phần chữ (ký tự mỗi nguồn, cắt từ cuối) của MỘT lời gọi model — ghi chú đầy đủ ở `_note` trong `appsettings.json` |
| `Poc:RuntimeCheck:{Enabled,BrowserPath,AutoInstall,AutoInstallTimeoutSeconds}` | true / trống / true / 300 | Tầng chạy POC trong Chromium headless ([getting-started.md](getting-started.md#chromium-cho-tầng-kiểm-poc)). `BrowserPath` trống ⇒ dùng bộ Playwright của máy, chưa có thì tự tải một lần (`AutoInstall`). Fail-open toàn phần |
| `Budget:{Enabled,Period,SystemUsdLimit,PerProjectUsdLimit}` | true / Monthly / 0 / 0 | Trần chi phí USD. 0 = không giới hạn scope đó (opt-in thực tế). Sửa được ở trang Settings, có hiệu lực ngay |
| `Encryption:ApiKeyKey` | ⚠️ có giá trị commit sẵn | **Bắt buộc nạp qua env**; khóa cũ trong git history coi như đã lộ — xoay khóa trên môi trường thật |
| `Serilog:*` | Console + File `Logs/ico-.log` xoay ngày, giữ 14 ngày, 50MB/ngày | Mức log/sink đổi không cần build |
| `DatabaseLog:{Enabled,MinimumLevel,RetentionDays}` | true / Warning / 30 | **Không có trong `appsettings.json`** — mặc định nằm ở `Configuration/DatabaseLogSettings`; muốn đổi thì thêm section vào appsettings hoặc đặt biến môi trường (`DatabaseLog__Enabled=false`...). Chép log từ mức đó trở lên vào bảng `SystemLogs` (màn **System Logs**). Độc lập với `Serilog:MinimumLevel`. `RetentionDays` ≤ 0 = không tự xoá. Đổi cần khởi động lại — xem [operations.md](operations.md#log-warningerror-trong-db-màn-system-logs) |
| `Otel:{Enabled,ServiceName,OtlpEndpoint}` | false / ICOGenerator / trống ⇒ gRPC `localhost:4317` | OpenTelemetry opt-in. Đừng bật khi chưa có collector — dev/demo chạy `docker compose -f docker-compose.otel.yml up -d` là có sẵn |

> Màn hình **Settings** trong app sửa được một phần cấu hình này lúc runtime (qua `AppSettingsFileStore` ghi ngược vào file) — vì vậy trang Settings được bảo vệ chặt (`SettingsManage`, mặc định chỉ Admin).
